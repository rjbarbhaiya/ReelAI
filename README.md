# 🎬 ReelAI — Turn Travel Reels into Trip Plans 🌍

**ReelAI** is an AI-powered web app that transforms travel TikToks and Instagram Reels into interactive trip planners.  
Paste a reel link, and ReelAI automatically extracts the destinations mentioned — from speech, captions, or on-screen text — and plots them on a map so you can explore and plan your next adventure.

---

## 🚀 Features

- 🎥 **Video Ingestion** — Upload or paste a TikTok / Instagram Reel link  
- 🧠 **AI Location Extraction** — Detects destinations using speech-to-text, OCR, and NLP  
- 🗺️ **Interactive Map View** — Displays all extracted places with pins and details  
- 🧳 **Trip Planner** — Add locations to a personal itinerary and visualize routes  
- 🪄 **Automatic Geocoding** — Converts place names into coordinates via Google Maps / Mapbox APIs  
- 💾 **Storage Layer** — Save processed reels and itineraries for later use
